## 1.2 Build provenance
All ZIP entry timestamps read `1981-01-01` (the standard reproducible-build placeholder), and `META-INF/` contains `BNDLTOOL.SF` / `BNDLTOOL.RSA` rather than typical `CERT.SF`/`CERT.RSA`. Combined with root-level `*.version` stamp files for every AndroidX/Firebase/Play-Services artifact, `androidsupportmultidexversion.txt`, `assets/dexopt/baseline.prof(m)`, and manifest `<meta-data>` entries `com.android.vending.splits`, `com.android.vending.derived.apk.id`, `com.android.stamp.source = https://play.google.com/store`, `com.android.stamp.type = STAMP_TYPE_STANDALONE_APK` — this is a **standalone APK generated by `bundletool` from an Android App Bundle (.aab), as distributed via Google Play** (Play App Signing), not a developer-built debug/release APK directly from Gradle.

## 1.7 Assets of note
- `assets/bkash/` — a full **bKash payment WebView checkout kit** (HTML/CSS/JS/fonts: `checkout_120.html`, `checkoutSuccess.html`, `checkoutFailure.html`, bootstrap + jQuery + a `bKash-checkout(.sandbox).js` SDK script). This is bKash's own hybrid-WebView checkout bundle, shipped as static assets.
- `assets/ml/nid_classifier.tflite` — an on-device TensorFlow Lite model, consistent with local classification of Bangladeshi National ID (NID) card images during the eKYC flow.
- `assets/fonts/kohinoor_bangla_{bold,regular}.otf` — dedicated Bengali-script fonts.
- `assets/help/*_terms_and_conditions.html`, `assets/help/img/a_*.png` — bundled in-app help/FAQ content with ~40 numbered screenshots.
- `assets/org/threeten/bp/TZDB.dat` — ThreeTenABP timezone database (date/time library backport).
